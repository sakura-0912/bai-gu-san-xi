# 白骨三戏 · 火眼

《西游记》第二十七回“三打白骨精”的网页叙事战术 RPG 竖切版。纯前端静态页面，直接打开 `index.html` 即可游玩，也可通过 GitHub Pages 在线访问。

## 在线游玩

启用 GitHub Pages 后访问：

https://sakura-0912.github.io/bai-gu-san-xi/

## 本地游玩

直接用浏览器打开 `index.html`，或在目录里起一个静态服务：

```powershell
node build/app/server.mjs --port=4173
```

## 玩法

- 在三个场景中开启法眼，点查可疑人物与器物上的破绽。
- 每场至少两处破绽可“以证啐破”；查满三处会先击破对应骸障。
- 也可以在“举棒便打”与“护师退避”之间取舍：一个削弱真身却伤师父信任，一个保住心印却养强妖怪。
- 终局真身战会读取你找到的证物、八戒是否掳手、山神是否作证与师父心印。
- 键盘：Enter / Space 推进，数字键选择，F 开关法眼；右上角可静音。
